# Estuco

**Rol:** formateador · **Configuración:** ninguna

Estuco da su forma canónica (R7) al código fuente de los seis lenguajes.

- <a id="estuco-1"></a>**Sin opciones.** Dos programas con la misma estructura se escriben igual, carácter por carácter. `estuco-1`
- <a id="estuco-2"></a>**Idempotencia.** Aplicarlo dos veces produce lo mismo que aplicarlo una. `estuco-2`
- <a id="estuco-3"></a>**Preservación.** La representación intermedia antes y después tiene la misma identidad. `estuco-3`
- <a id="estuco-4"></a>**Obligatoriedad.** El código fuente que no está en forma canónica se rechaza. `estuco-4`
